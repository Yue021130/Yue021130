# Linux 端口排查与管理速查表

围绕 **「查看端口 → 管理防火墙 → 定位进程」** 这一完整链路，汇总所有命令：

---

## 一、查看系统开放端口

| 目的                     | 命令                         |
| ------------------------ | ---------------------------- |
| 查看所有监听端口（推荐） | `ss -tulnp`                  |
| 只看 TCP 监听            | `ss -tlnp`                   |
| 只看 UDP 监听            | `ss -ulnp`                   |
| 传统方式查看             | `sudo netstat -tulnp`        |
| 查看端口被哪个进程占用   | `sudo lsof -i :<端口>`       |
| 本机扫描开放端口         | `sudo nmap -sT -O localhost` |

---

## 二、UFW 防火墙管理

| 目的                  | 命令                                          |
| --------------------- | --------------------------------------------- |
| 查看当前放行规则      | `sudo ufw status`                             |
| 查看带编号的规则      | `sudo ufw status numbered`                    |
| **开放一个端口**      | `sudo ufw allow <端口>/tcp`                   |
| **关闭/删除一个端口** | `sudo ufw delete allow <端口>/tcp`            |
| 按编号删除规则        | `sudo ufw delete <编号>`                      |
| 只允许特定 IP 访问    | `sudo ufw allow from <IP> to any port <端口>` |
| 拒绝某端口            | `sudo ufw deny <端口>/tcp`                    |

---

## 三、根据 PID 定位进程详情

| 目的                         | 命令                                     |
| ---------------------------- | ---------------------------------------- |
| 查看进程基本信息             | `ps -p <PID> -f`                         |
| 查看进程详细信息             | `ps -p <PID> -F`                         |
| 查看进程打开的文件/端口      | `sudo lsof -p <PID>`                     |
| 查看进程状态（内存、线程等） | `cat /proc/<PID>/status`                 |
| 查看进程启动命令             | `cat /proc/<PID>/cmdline \| tr '\0' ' '` |
| 查看进程工作目录             | `pwdx <PID>` 或 `ls -l /proc/<PID>/cwd`  |
| 查看进程可执行文件           | `ls -l /proc/<PID>/exe`                  |
| 实时监控该进程               | `top -p <PID>`                           |

---

## 四、完整排查流程示例

```bash
# 1. 发现可疑端口 8003
sudo ss -tulnp | grep 8003

# 2. 找到占用该端口的 PID
sudo lsof -i :8003

# 3. 根据 PID 查看进程详情
ps -p <PID> -F
sudo lsof -p <PID>

# 4. 决定是否通过防火墙关闭
sudo ufw delete allow 8003/tcp
sudo ufw status
```
